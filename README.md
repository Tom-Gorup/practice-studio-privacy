# Practice Studio privacy and support pages

Standalone privacy and support pages for the Practice Studio iPhone app. This repository is private while the site and email forwarding are configured.

- `index.html`: privacy policy page for the eventual public root URL
- `support.html`: support page
- `home.html`: optional landing page
- `Privacy-Policy.md`: editable policy text

The approved site domain is `practice.cybrpulse.com`. The contact addresses are `privacy@cybrpulse.com` and `support@cybrpulse.com`. Before publication, verify email forwarding, confirm the content against the shipped app, and configure hosting. Do not use this repository URL as the App Store privacy URL while it is private.
