# Practice Studio privacy and support pages

Standalone privacy and support pages for the Practice Studio iPhone app. This repository is a draft and is private until the dedicated contact address and public URL are chosen.

- `index.html`: privacy policy page for the eventual public root URL
- `support.html`: support page
- `home.html`: optional landing page
- `Privacy-Policy.md`: editable policy text

Before publication, add the approved contact address to the policy and support pages, confirm the content against the shipped app, then configure hosting and the chosen domain. Do not use this repository URL as the App Store privacy URL while it is private.
